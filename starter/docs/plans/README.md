# Kế hoạch việc lớn

- `active/` — kế hoạch đang làm hoặc tạm dừng. Tên file: `YYYY-MM-DD-<ten-viec>.md`.
- `completed/` — kế hoạch đã xong (đã điền mục "Kết quả"), giữ để tra lý do về sau.

Mẫu và luật dùng: skill careful-engineering, `references/memo-handoff.md` §1. Việc nhỏ một commit không
cần file ở đây — kế hoạch trong chat là đủ.

Trước khi chuyển một kế hoạch sang `completed/`: quyết định còn hiệu lực ⇒ `docs/DECISIONS.md`, luật mới
⇒ `docs/REGRESSION-GUARD.md`, việc để lại ⇒ `docs/OPEN-ISSUES.md`. Thư mục `completed/` ít ai đọc.
