# Hướng dẫn cho Claude Code

Claude Code không tự đọc `AGENTS.md` khi repo có `CLAUDE.md`, nên dòng dưới nhập nó vào. Mọi hướng dẫn
chung viết trong `AGENTS.md` (nguồn duy nhất, Codex cũng đọc). Giữ dòng `@AGENTS.md` đứng riêng, không
đặt trong backtick hay khối code — nếu không nó sẽ không được nhập.
